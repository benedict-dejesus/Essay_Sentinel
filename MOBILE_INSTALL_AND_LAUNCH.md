# Browser Launch Guide

Essay Sentinel is now distributed as a mobile-first website rather than a native installer. Publish the static site using the included GitHub Pages workflow, then open its URL in a mobile browser.

On an iPhone, open the site in Safari and use the browser’s share controls to add a shortcut to the Home Screen. On Android, open the site in Chrome and use the browser menu to add a shortcut to the Home Screen. These shortcuts open the browser-based Essay Sentinel site; they do not install an APK or iPhone package.

After opening the site, choose a light or dark appearance in **Settings**, select or create an assignment rule set, then start a review from the **Reviews** tab. Review records and preferences remain in that browser’s local storage until they are deleted.

For repository setup and hosting instructions, see [GITHUB_PAGES_DEPLOYMENT.md](./GITHUB_PAGES_DEPLOYMENT.md).
